# Research: Pronóstico de demanda

- Base: mediana móvil robusta para no dejar que un único pico domine.
- Demanda censurada: ventas perdidas se añaden como señal, con menor confianza si el agotado no fue medido.
- Promoción/precio: se etiquetan períodos y se evita extrapolarlos sin corrección.
- Resultado: valor central más intervalo; nunca una cifra presentada como certeza.
- Decisión de compra: recomendación revisable, no automatización irreversible.
